Upload the approved VRV Global cinematic hero loop here:

- `vrv-hero-supply-chain.mp4`  (H.264 MP4, web-optimized, ≤ ~8 MB)
- `vrv-hero-supply-chain.webm` (VP9/AV1 WebM, web-optimized)

And the poster image to:

- `/public/images/hero/vrv-hero-poster.jpg` (first frame, ≥ 1920×1080)

Specs: 1920×1080+ (16:9 or wider), 20–35s, loopable, **no audio**, no text/logos.
Storyboard: rubber plantations → tapping → rubber processing → copper cathodes →
aluminium → satellite farm/mine mapping & traceability → happy farmer & children.

Until these files exist, `HeroVideoBackground` falls back to an existing
commodity image (the hero is never blank). The video is muted, looped, plays
inline, and does not autoplay for reduced-motion users.
